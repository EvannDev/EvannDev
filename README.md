### Hi, I'm Evann 👋

Platform Engineer based in Montréal. I build Kubernetes platforms the GitOps way, and I send fixes upstream to the cloud native tools I run.

#### 🔧 What I'm building

- **[dns-rs](https://github.com/EvannDev/dns-rs)**: a network-wide DNS sinkhole in Rust, a modern take on Pi-hole built for containers and stateless replicas. It handles blocklists over HTTPS, hot reload, Prometheus metrics, a Helm chart tested end to end in kind, and releases to GHCR. [Docs](https://evanndev.github.io/dns-rs/)
- **platform** *(private)*: my homelab. Three Raspberry Pi 4 running Talos Linux, driven entirely by Argo CD. It uses Cilium (kube-proxy replacement, L2 LoadBalancer, Hubble), agentgateway on the Gateway API, cert-manager, External Secrets, VictoriaMetrics, vcluster environments through kro, and a team of kagent AI agents.
- **[blog](https://blog.evann-deb.fr)**: *Carnet de bord*, where I write (in French) about running that homelab. Built with Astro.
